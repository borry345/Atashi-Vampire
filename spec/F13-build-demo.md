### F13. 빌드와 시연 영상 **[사용자 수행]**

구현 대상은 빌드 가능한 프로젝트 설정까지이고, 빌드 실행·영상 녹화·업로드·GIF 제작은 사용자가 직접 한다.

**수용 기준**
- (사용자 수행) 주어진 릴리스 시점에 Windows 실행파일(zip 등)이 GitHub Releases에 업로드되어 있어야 한다.
- (사용자 수행) 주어진 개발자 PC가 아닌 다른 Windows PC에서 압축 해제 후 실행하면 타이틀 화면이 나타나고, 플레이 루프를 사망 또는 클리어까지 한 번 끝까지 경험할 수 있어야 한다. 이는 테스터 확인으로 검증한다.
- (구현) 주어진 빌드 설정에서 `StreamingAssets`의 JSON 7종과 에셋 키 레지스트리 데이터가 빌드에 포함되어야 하고, 빌드 폴더에서 JSON 원본 파일을 직접 편집할 수 있어야 한다 (F11 연계).
- (4회차 수정) (구현) 주어진 측정용 Development Build와 배포용 릴리스 빌드는 **둘 다 개발자 모드(F19)를 포함**해야 한다(Q40). 두 빌드의 구분은 Development Build 플래그(Profiler 연결 가능 여부)뿐이며, 릴리스 빌드에서 개발자 모드는 커맨드라인 인자 `--dev` 없이는 활성화되지 않아야 한다.
- (5회차 신규) (사용자 수행) 개발자 모드 오버헤드 비교용 세 번째 빌드(`SURVIVOR_NO_DEV` 심볼로 개발자 모드 코드를 제거한 빌드, F19)는 **배포하지 않는다**(GitHub Releases에 올리지 않는다).
- (사용자 수행) 시연 영상 1~2분이 YouTube에 업로드되고 링크 공개 상태여야 한다.
- (사용자 수행) 시연 영상 길이가 1분 이상 2분 이하여야 한다.
- (사용자 수행) `README.md` 상단에 GIF 1개가 포함되어야 한다.
- 비공개 → 공개 전환 시점: 1차 MVP 완성 시 저장소를 공개로 전환한다 (사용자 수행). 공개 전환 전 비밀 정보(키, 개인 경로 등)가 포함되지 않았는지 확인해야 한다.
- (4회차 수정) (사용자 수행) 주어진 테스터 배포용 `README.md`(또는 Releases 설명)에 ① zip을 풀고 실행해야 함(zip 안에서 직접 실행하면 `StreamingAssets`가 없어 실패), ② 지원 환경 Windows 10/11 64비트, ③ SmartScreen 경고 안내, ④ 최소 요구사항 **"1280x720 이상 작업 영역"** 이 들어 있어야 한다(Q46, 기본값 채택).
