### 5.8 중앙 틱 (Core 계약, IMP-LOOP 구현) (2회차 수정, A8)

```csharp
namespace Survivor.Core
{
    public enum TickStrategyKind { PerObjectFixedUpdate = 0, CentralTick = 1 }
    public enum TickGroup { Monsters = 0, Projectiles = 1 }   // Projectiles = player W1/W4/E1 + enemy M3 projectiles; (rev 13) own file TickGroup.cs

    /// Per-step logic for monsters and projectiles only (F17 scope).
    public interface IUpdatable
    {
        EntityHandle Id { get; }
        TickGroup Group { get; }
        void Tick(in StepContext context);   // writes own state only; side effects via context.Commands
    }

    public interface ITickStrategy
    {
        TickStrategyKind Kind { get; }
        void Register(IUpdatable updatable, GameObject host);   // per-object: binds and enables host's self ticker
        void Unregister(IUpdatable updatable);                  // safe during RunGroup
        void RunGroup(TickGroup group, in StepContext context); // per-object: no-op
        int RegisteredCount(TickGroup group);
        void Clear();
    }
}
```

- (2회차) 셀프 티커(`MonsterSelfTicker`, `ProjectileSelfTicker`, Strategies)는 `SelfTickStrategy(IStepClockReader clock)`가 `Register` 때 넣어 준 `IStepClockReader`와 `IUpdatable`만 안다. `FixedUpdate`에서 `if (!_clock.StepActive) return; _owner.Tick(_clock.CurrentContext);`만 한다. 1회차의 정적 `SimulationContextHub`와 `SimulationClock` 직접 참조는 없앴다(Strategies → Simulation 참조 위반이었다). `IStepClockReader`의 구현은 `SimulationClock`이며 조립 루트가 `SelfTickStrategy` 생성자에 넣는다.
- (15회차, 웨이브 2b 구현 확정 — main b9f8ea5, `Scripts/Strategies/Tick/*`) 네임스페이스는 `Survivor.Strategies.Tick`이다(Pool은 `Survivor.Strategies.Pool`, Spatial·Targeting은 `Survivor.Strategies` — 영역마다 다르며 통일하지 않는다). Tick 코드는 `Survivor.Simulation`을 참조하지 않는다(Core만).

```csharp
namespace Survivor.Strategies.Tick
{
    public sealed class CentralTickStrategy : ITickStrategy   // F17 B, TAC-F17-1
    {
        public CentralTickStrategy();
        //   Register: host unused; already registered -> InvalidOperationException. Unregister: not registered -> InvalidOperationException;
        //   nulls the slot (compacted at the next RunGroup, before and after iterating). Register during RunGroup -> pending list,
        //   appended when it ends. RunGroup re-entry -> InvalidOperationException.
    }

    public sealed class SelfTickStrategy : ITickStrategy        // F17 A, TAC-F17-2
    {
        public SelfTickStrategy(IStepClockReader clock);        // null -> ArgumentNullException
        //   Register: binds host's MonsterSelfTicker (Monsters) / ProjectileSelfTicker (Projectiles) and enables it;
        //   host without the ticker -> InvalidOperationException. Unregister/Clear: disable + unbind (a destroyed host is skipped). RunGroup: no-op.
    }

    [DefaultExecutionOrder(-500)] [DisallowMultipleComponent]
    public sealed class MonsterSelfTicker : MonoBehaviour    { public IUpdatable Owner { get; } }   // ★ (rev 15) Owner; internal Bind/Unbind
    [DefaultExecutionOrder(500)] [DisallowMultipleComponent]
    public sealed class ProjectileSelfTicker : MonoBehaviour { public IUpdatable Owner { get; } }   // ★ (rev 15) Owner; internal Bind/Unbind
    //   FixedUpdate: if (_clock == null || !_clock.StepActive) return; _owner.Tick(_clock.CurrentContext);

    public sealed class SelfTickTemplateDecorator : IEntityTemplateDecorator
    {
        public void Decorate(GameObject template, EntityCategory category);
        //   Monster -> disabled MonsterSelfTicker, PlayerProjectile/EnemyProjectile -> disabled ProjectileSelfTicker, others untouched;
        //   idempotent; null template -> ArgumentNullException
    }
}
```
