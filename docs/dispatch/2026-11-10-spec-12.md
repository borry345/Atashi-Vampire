**S1-1 몹–플레이어 접촉 멈춤**(사용자 확정). 수용 기준 신규:
1. 주어진 몬스터는 플레이어와의 중심 거리가 **접촉 거리(몬스터 반지름 + 플레이어 반지름)** 미만이 되도록 이동하지 않아야 한다. 한 스텝의 이동이 그 거리를 넘으면 접촉 거리까지만 이동한다(이동 방향은 기존 규칙 그대로). 이미 접촉 거리 안에 있으면(플레이어가 다가온 경우) 그 스텝에 이동하지 않으며, 뒤로 물러나지도 않고 플레이어를 밀지도 않는다(Q50, 기본값 채택).

**S6-3 스폰 즉시 토글** (12회차 보강): 적 제어의 기존 "스폰 중단"을 보강한다 — 주어진 개발자 모드의 **일반 스폰 켜기/끄기 토글**은 판 진행 중에 누르면 **다음 스텝부터 즉시** 적용되어야 한다(판을 다시 시작하지 않아도 된다). 끔은 스폰 테이블 스폰과 N 유지 재스폰을 모두 멈추고, 보스 등장(10분)·보스 소환(패턴 ②)·"즉시 N기 생성"은 멈추지 않는다(Q50). 켬이면 그 스텝부터 테이블대로 재개하며 꺼져 있던 동안의 스폰을 몰아 스폰하지 않는다(F03 "버림" 규칙과 같다). 토글은 스텝 명령으로 적용되어 같은 시드·같은 스텝에 같은 토글을 넣으면 결과가 같아야 한다(결정론 유지). "다음 판부터" 적용되는 기존 스폰 정책 설정(특정 종만·N 유지)은 그대로 둔다.

**S6-4 줌** (12회차 신규): 카메라 orthographic size를 기본 9에서 **4.5~27** 범위로 조정(리셋 포함, Q50). 표시 전용 — 스폰 반경·디스폰 거리·격자·판정은 월드 단위라 바뀌지 않으며, 줌 아웃 중 스폰이 화면 안에 보이는 것은 허용(F03 S1-4 괄호). 개발자 모드가 아니면 항상 9. 측정 시작 거부 조건에 넣지 않는다(Q50 — 표시만 바뀜).

**S6-5 투사체별 타깃 선** (12회차 보강): 시각화 "타깃 탐색 결과 표시"에 **유도 투사체(W4·E1 등 매 스텝 재추적하는 투사체)가 현재 추적 중인 타깃까지의 선**을 포함한다. 무기→발사 시점 타깃 선은 그대로. 꺼져 있으면 비용 0 규칙 동일.

**S6-6 커맨드 로그** (12회차 신규): 오버레이의 **마지막 명령 결과 한 줄**(현재 "Level up queued." 같은 문구가 뜨는 자리)을 **최근 명령 로그 여러 줄**로 넓힌다 — 최신 위, **10줄**(Q50 기본값), 각 줄은 스텝 번호 + 명령 이름 + 결과(수행/거부 사유). 사용자가 내린 모든 개발자 명령(수행·거부 모두)이 여기에 남아야 한다. **상자 효과 결과(F04 S2-2의 최근 목록)**도 같은 로그에 스텝 순으로 섞여 표시되어야 한다("Chest: 투사체 Lv 3→4" 형식, 이름은 데이터 `displayName`, 레이블은 영어). 상자 결과는 시뮬레이션이 목록으로 보관하므로 오버레이가 닫혀 있던 동안의 것도 열면 보인다. 새 판 시작 시 지우지 않고 세션 동안 유지하며, 파일로 내보내지 않는다(충돌 로그·CSV와 별개, Q50). 로그 표시는 시뮬레이션 상태를 바꾸지 않으며, 명령 기록은 사용자 조작 시점 1회라 "닫혀 있으면 비용 0" 규칙과 충돌하지 않음을 한 구절.

**S6-7 `(evolved)` 정정**: 11회차 현황 패널 문단·수용 기준의 "진화 무기는 진화 표기" → "진화 무기는 `(evolved)` 표기(영어 레이블 원칙)". (12회차 수정) 표기.
