## 3. 할 일
### T1. 5.9 엔진 전략 (23회차 수정)
- 이벤트 생성 규칙을 "R5 상태 순변화"로 고쳐 쓴다: ★ 보고 상태 집합(예: `_reportedPairs : PairSet` — 이름은 당신이)과 후보 집합(`_activePairs` ∪ 이번 스텝 콜백 쌍). 각 후보 쌍에 대해 `exact = CircleMath.Overlaps(bodyA.Position, bodyA.Radius, bodyB.Position, bodyB.Radius)`(R5 단일 소유 함수, 자체판과 **같은 인자 순서·같은 함수**)를 계산하고 `exact != _reportedPairs.Contains(pair)`이면 Enter/Exit + 집합 갱신. Box2D가 Exit을 냈지만 R5가 아직 참인 쌍(허용오차 반대 방향)의 처리, `Unregister`(바디 제거)·`Clear`·`NotifyRadiusChanged` 때 두 집합의 정리, 바디 위치 조회 경로(동기화기·`CollisionBodyLink` 중 어디서 `CollisionBody`를 얻는지 — 코드를 보고 확정), 비용 한 줄(후보 쌍 수만큼 제곱거리 비교). 17회차 ③ 필터 문단은 이 규칙에 **포함**된다고 적는다(순변화 = R5 상태의 순변화).
- `CancelledTransitionCount`의 의미 갱신(또는 ★ 새 카운터, 예: `BoundaryDeferredCount` — Box2D 접촉 중이나 R5 거짓인 쌍 수). 진단 공개 멤버는 [기본값] 1개까지.
